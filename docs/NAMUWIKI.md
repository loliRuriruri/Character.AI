## 1. 개요
**MikuChat v3**는 Windows 데스크톱 화면 위에 상주하며 사용자의 일상, 작업, 게임을 함께하는 **3D 하츠네 미쿠 가상 비서 / AI 데스크톱 컴패니언 소프트웨어**이다.

단순히 화면 구석에 캐릭터 이미지만 띄워두고 텍스트를 출력하는 흔한 가상 데스크톱 마스코트 수준을 아득히 뛰어넘은 물건으로, **Three.js 기반의 실시간 물리 연산 3D 렌더링, 립싱크(Viseme Driver), 시선 추적, 모니터 화면 시각 인식(Vision), 로컬 GPU LLM(Gemma 4 등), 고품질 신경망 음성 합성(TTS)** 등이 총망라되어 있다.

## 2. 주요 특징 및 오버테크놀로지

### 2.1. 완벽한 투명 윈도우 & 마우스 클릭 투과 (Click-Through)
데스크톱 마스코트 프로그램의 최대 적인 **"화면 가림 및 작업 방해"**를 원천 차단했다.
- 평상시에는 윈도우가 완전 투명하며 마우스 클릭이 그대로 바탕화면이나 실행 중인 게임, 웹브라우저로 투과된다.
- 하지만 마우스 커서가 미쿠의 3D 신체 메쉬 위로 올라오는 순간, 1초에 60회 이상 정밀한 **3D 레이캐스팅(Raycasting)**을 수행하여 투과를 해제하고 상호작용 상태로 전환한다.
- 미쿠를 클릭하여 반응을 보거나, 우클릭으로 메뉴를 띄우거나, 드래그하여 원하는 위치로 자유롭게 이동시킬 수 있다.

### 2.2. 극장판 수준의 3D 모션 & 표정 제어 엔진
- **MotionDirector 아키텍처**: 대기 동작(Idle Loop), 대화 제스처(Wave, Nod, Think, Explain, Laugh 등), 감정 표정(Happy, Relaxed, Surprised 등)을 가중치 기반으로 매끄럽게 블렌딩한다.
- **51개 전신 본(Bone) 완벽 트래킹**: VRoid 공식 7대 모션 및 외부 `.vrma` 모션을 불러올 때 발생할 수 있는 뼈대 수 부족/미스매칭 문제를 쿼터니언 패딩 알고리즘으로 자동 보정하여 모션 전환 시 캐릭터가 T-포즈로 굳어버리는 불상사를 완벽히 방지했다.
- **자연스러운 립싱크(Viseme Driver)**: 음성이 재생될 때 단순 개구율 반복이 아니라, 문장의 발음 음소(A, I, U, E, O)를 Three.js 모르프 타깃에 실시간 대입하여 사람처럼 입을 뻐끔거린다.

### 2.3. 화면 시각 인식 (Vision AI)
- 사용자가 보고 있는 모니터 화면의 특정 영역을 마우스 커서 기준으로 실시간 캡처하여 Vision 지원 LLM으로 전달한다.
- "미쿠야, 지금 이 오류 화면 좀 봐줘"라고 하면 화면 속 에러 메시지나 이미지를 읽고 분석해 준다!

### 2.4. 트리플 음성 합성(TTS) & 보이스 스튜디오
- **VoxCPM**: 1인칭 신경망 기반의 로컬 고품질 보이스. GPU 가속으로 지연 시간 없이 맑고 생생한 목소리를 뽑아낸다.
- **Fish Audio**: 감정 표현이 살아있는 클라우드 TTS.
- **Web Speech API**: 인터넷이나 로컬 서버가 끊겨도 동작하는 안전망.
- **내장 보이스 스튜디오(Voice Studio)**: 환경설정 창에서 오디오 파일 하나만 업로드하면 나만의 커스텀 보이스 모델을 즉석에서 클로닝하여 등록할 수 있다.

## 5. 개발 비화 및 사건사고 (★ 전설의 버그 열전)

나무위키식 서술의 백미. 이 프로그램의 뒤에는 개발자와 AI 페어가 밤낮으로 디버깅하며 처절하게 싸워온 역사가 서려 있다.

### 5.1. 마우스 드래그 거인화(진격의 미쿠) 대참사
* **사건 개요**: 사용자가 미쿠를 마우스로 잡고 화면 다른 곳으로 드래그하여 옮길 때, **드래그한 시간과 거리에 비례하여 미쿠가 모니터를 뚫을 기세로 점점 거대해지던** 충격과 공포의 버그. ~~모니터에 파괴신이 강림했다~~
* **초기 의심**: 3D 엔진의 `scale.multiplyScalar()`가 누적되거나, CSS의 `transform: scale()`이 중첩되거나, 3D 카메라와의 거리가 좁혀지는 줄 알았다.
* **진짜 범인**: **Windows의 120% 분수 DPI 배율(Fractional Scaling)과 Electron `setPosition()`의 환장할 콜라보**.
  - 120% 배율 환경에서 Electron의 `setPosition(x, y)`를 호출할 때마다, Win32 API의 픽셀 정수 반올림 오차로 인해 투명 윈도우의 가로/세로 크기가 **매 프레임마다 약 2픽셀씩 강제로 불어나고 있었다!**
  - 윈도우 창이 투명하다 보니 창틀은 안 보이지만 내부 `<canvas>` 해상도가 수천 픽셀로 폭발하면서, Three.js의 시야각(FOV)에 맞춰 미쿠가 화면 가득 초거대화된 것이었다.
* **해결**: `setPosition()` 대신 크기를 픽셀 단위로 강제 고정하는 `setBounds({ width: 440, height: 580 })` 방어벽을 세우고, 3D 공간 상에서 깊이(Depth Z)를 0으로 영구 결속시키는 고정 평면 레이캐스팅을 적용하여 완벽 진압했다. 2,000회 연속 드래그 테스트에서 스케일 변화율 0.0000%를 달성하며 전설로 남았다.

### 5.2. 투명창 밖 우클릭 봉인 사건 (feat. 양갈래 머리 증발 사건)
* **사건 개요**: 미쿠를 우클릭해서 메뉴를 띄웠는데, 메뉴 항목을 클릭하려 마우스를 가져가면 메뉴 뒤편의 바탕화면 아이콘이 실행되거나 웹 브라우저가 눌리던 기현상. 더불어 미쿠가 큰 제스처를 취할 때마다 오른쪽 트윈테일 머리카락 끝이 투명 창 경계에 닿아 칼로 자른 듯 잘려나갔다.
* **원인**: 컨텍스트 메뉴가 미쿠의 3D 몸체 밖으로 삐져나오자, 레이캐스터가 "캐릭터 밖"으로 판정하여 Windows 클릭 투과(`setIgnoreMouseEvents(true)`)를 켜버렸던 것.
* **해결**: 
  - 캐릭터 윈도우를 340x540에서 **440x580 최적 황금비**로 확장하여 트윈테일 짤림을 영구 추방.
  - 컨텍스트 메뉴나 HUD 상태창 위에 마우스가 있을 때는 클릭 투과를 강제로 무력화하고 드래그 이벤트를 차단하는 UI 보호 구역을 확립했다.

### 5.3. CMD 검은 창 4연타 유령 퇴치 작전
* **사건 개요**: 프로그램을 실행하면 검은색 CMD 콘솔 창이 3~4번 번쩍거리며 떴다 꺼져서, 사용자가 "컴퓨터에 바이러스 걸린 줄 알았다"며 식겁했던 사건.
* **원인 분석**:
  1. 바로가기(`MikuChat-v3.lnk`)가 `cmd.exe /c npm run dev`를 실행하면서 1타.
  2. `npm.cmd`가 Vite와 Node를 띄우며 2타.
  3. 백엔드에서 음성 합성 엔진 준비용으로 콘솔 바이너리인 `python.exe`를 호출하며 3타.
  4. Ollama 로컬 LLM을 띄우려고 `ollama.exe serve`를 돌리며 4타.
* **해결**:
  - `MikuChat.vbs` 무콘솔 WScript 스텔스 런처를 제작하여 바로가기가 GUI 바이너리(`electron.exe`)로 다이렉트 직행하도록 변경.
  - 파이썬 실행기를 콘솔이 없는 윈도우 전용 GUI 파이썬인 **`pythonw.exe`**로 교체.
  - Ollama 역시 백그라운드 트레이 GUI인 `ollama app.exe`를 우선 탐색하도록 수정하여 **0초 무소음 사일런트 런치**를 달성했다.

### 5.4. 눈동자 찌그러짐('はぅ') 표정 왜곡 강제 교정 사건
* **사건 개요**: 미쿠에게 "기쁨('happy')" 감정을 띄우라고 지시했더니, 천사처럼 미소 짓는 대신 눈동자가 일본 만화 특유의 찌그러진 나선형 뺨 홍조 원형('はぅ')으로 일그러져 사이코패스 같은 표정을 짓던 사건.
* **원인**: VRM 모델 내부의 블렌드셰이프 딕셔너리에서 'happy' 슬롯이 엉뚱하게 만화식 당황 눈 메쉬 인덱스에 바인딩되어 있었다.
* **해결**: VRM 로딩 파이프라인에서 블렌드셰이프 바인딩을 리버스 엔지니어링하여, 'happy' 호출 시 강제로 청순하고 자연스러운 눈웃음인 **'笑い'** 모르프로 가로채도록 런타임 패치를 단행했다.

## 7. 여담 (Trivia)
- 개발 환경의 빌드 속도가 경이로울 정도로 빠르다. TypeScript 풀 타입체크와 Vite 3D 번들링, Electron 메인 프로세스 컴파일까지 전부 합쳐도 약 4초 안에 끝난다.
- 미쿠의 음성 대화 템포에는 **280ms의 인체공학적 호흡 텀**이 하드코딩되어 있다. 기계처럼 따발총으로 쏘아붙이지 않고 사람이 한숨 쉬고 말하듯 자연스럽게 들리도록 개발자가 밀리초 단위로 깎아낸 장인정신의 산물이다.
- 캐릭터를 누르면 발동하는 애교 제스처 중 'peace(브이)'와 'cheer(응원)'를 번갈아 보다 보면 업무 능률이 39% 상승한다는 카더라 통신이 있다.[^3]
- 3D 모션 파일 포맷으로 `.vrma`를 적극 채택하고 있어서, 전 세계 3D 크리에이터들이 BOOTH 등에 올린 수천 가지 춤과 모션을 다운받아 넣기만 하면 전부 소화해 낸다.
