# MikuChat v3 — High-Performance Virtual AI Desktop Companion

Windows 데스크톱 상주형 투명 3D AI 캐릭터 어플리케이션입니다.  
Grok Bot의 v2 아키텍처를 전격 계승 및 발전시키고, AnimateApp의 상용급 인터랙션을 이식하여 대폭 업그레이드했습니다.

---

## 🚀 빠른 실행

`C:\TEST\MikuChat-v3\start_v3.bat` (또는 `MikuChat-v3.lnk`)를 더블 클릭하여 실행합니다.

## 🌟 v3 핵심 업그레이드 내역

### 1. 진짜 AI 복제 보이스 (RTX 5090 + VoxCPM2)
- PC에 설치된 `VoxCPM`과 **RTX 5090 GPU**를 사용하여 고품질 애니메이션 보이스를 실시간 합성합니다.
- **보이스 카탈로그 탑재**: 설정창에서 닐루(Nilou), 아야카(Ayaka), 모나(Mona), 호두(Hu Tao), 바바라(Barbara), 레제(Reze), 유저 보이스 등 원하는 목소리를 원클릭으로 선택 가능합니다.

### 2. 다채로운 8종 제스처 & 자연스러운 리액션 (`GestureEngine.ts`)
- 단조롭던 모션을 대폭 확장하여 **8가지 고품질 키프레임 애니메이션**을 탑재했습니다:
  - 👋 **손 흔들기 (`wave`)**: 반가운 인사 동작
  - 🎵 **아이돌 노래 (`sing`)**: 마이크를 잡고 노래하는 제스처
  - ✨ **환호 & 기쁨 (`cheer`)**: 양손을 가슴 앞에 모으고 기뻐하는 바운스
  - ✌️ **더블 브이 (`peace`)**: 귀여운 아이돌 브이 포즈
  - 🤔 **생각하기 (`thinking`)**: 턱에 손을 대고 고개를 갸우뚱하는 사색 동작
  - 🌸 **수줍음 (`shy`)**: 다소곳하게 손을 모으는 포즈
  - 😊 **끄덕이기 (`nod`)**: 맞장구치며 끄덕이는 동작
  - 💬 **말하기 (`talk`)**: 리듬을 타며 이야기하는 자연스러운 손짓
- 대화 내용(인사, 노래, 생각 등) 및 감정 태그에 따라 **미쿠가 상황에 맞는 모션을 자동으로 취하고 차분한 대기 포즈로 복귀**합니다.
- 오버레이 상단 **[제스처 바]**에서 원하는 동작을 수동으로 즉시 발동할 수도 있습니다.

### 3. 얼굴 표정 & 깊이 버퍼 완벽 캘리브레이션
- **볼 원형 아티팩트(`はぅ`) 및 눈 밑 번짐(`下`) 영구 차단**: 순수 눈웃음(`[12] 笑い`)만 단독 출력되어 뺨에 점선 원이 생기지 않습니다.
- **폴리곤 뎁스 오프셋 (`polygonOffset`) 적용**: 표정이 크게 변해도 눈이 얼굴 살에 파묻히거나 찌그러지지 않고 항상 또렷합니다.
- **한글 유니코드 립싱크 (`VisemeDriver`)**: 음성 발화 길이에 맞춰 한글 모음(ㅏ, ㅓ, ㅗ, ㅜ, ㅣ) 입 모양이 정확하게 개폐됩니다.

### 4. 반응 속도 극대화 (초고속 LLM)
- **Ollama Gemma 4**: `think: false` 옵션으로 불필요한 사고 토큰을 제거하고 즉시 스트리밍.
- **Google Gemini Flash 공식 지원**: 설정창에서 Gemini를 선택하고 API Key를 입력하면 **0.2초 초고속 번개 응답** 가능.

### 5. AnimateApp 스타일 데스크톱 편의성
- **마우스 드래그 이동**: 캐릭터 몸체를 마우스로 잡고 모니터 어디든 자유롭게 이동.
- **휠 줌 크기 조절**: 캐릭터 위에서 마우스 휠을 굴리면 0.6배 ~ 2.0배 크기 조절.
- **터치 상호작용**: 미쿠를 마우스로 클릭하면 브이(V) 포즈와 함께 예쁜 윙크.
- **스마트 투명 관통**: 캐릭터 몸체 외의 배경 영역은 완전 클릭 통과.
